# 語法歧義、安全性與容錯測試矩陣

StructMark 的重要目標不是追求符號數最少，而是讓同一種輸入具有確定的 AST。V1.0 以以下案例建立回歸測試。

| 情境 | 輸入 | 預期行為 |
|---|---|---|
| 標題與 Setext | `#2 標題` / `文字\n---` | 前者為標題；後者不是 Setext 標題 |
| 標題尾端 ID | `#2 介紹 (#intro)` | `id=intro`，標題不包含 ID |
| 標題普通括號 | `#2 介紹 (補充)` | `(補充)` 屬標題文字 |
| 底線與清單 | `-[底線]` / `- 清單` | 前者行內樣式；後者清單項目 |
| 自動清單與數字清單 | `. 甲` / `1. 甲` | 不在同一個清單節點中混用 |
| 完成任務 | `- [o]` | task=true；`- [x]` 不是 1.1 原生完成狀態 |
| 連結圖片 | `[下載](file.png)` / `![展示](file.png)` | 不檢查副檔名，前者連結、後者圖片 |
| 中括號原文 | `[ordinary]` | 不符合完整連結等文法，保留原文 |
| Wiki | `[[page|title]]` | 獨立 Wiki 節點 |
| 文獻引用 | `[&smith2024]` | Citation 節點，不與 `&note` 混淆 |
| 註腳 | `[^1]` / `[^1]: ...` | 引用與定義是不同節點 |
| 行內指令 | `&kbd[Ctrl+C]` | Inline，不需要 `&end` |
| 區塊指令 | `&note ... &end` | Block，配對最近開啟指令 |
| 程式碼保護區 | `` `*[不解析]` `` | 內容保留為原始文字 |
| 原始資料保護區 | `&data[format=json] ... &end` | JSON 的 `{}` 不視為 StructMark 屬性 |
| 數學簡寫 | `$E=mc^[2]$` | 保留 LaTeX 語義，有限轉為 `E=mc^{2}` |
| 屬性附加 | `![alt](a.png)[width=600]` | 後置合法屬性附在圖片節點 |
| 孤立屬性 | `這裡 [#id]` | 不會把普通段落變成 ID 節點 |
| 格式未閉合 | `*[沒有結尾` | 不吞掉其後整份文件，產生診斷 |
| 區塊未閉合 | `&note\n文字` | 產生警告，盡可能保留已解析內容 |
| 缺少參照目標 | `&ref[missing]` | 產生語義診斷 |
| 危險 URL | `[x](javascript:alert(1))` | 不輸出可執行的危險連結 |
| HTML 原始內容 | `<script>...</script>` | 完整跳脫，不當作可信任 HTML |
| 隱藏註解 | `%%comment%%` | AST 可保留，但不渲染到 HTML |

## 已定稿的邊界與非目標

- 具有複雜 LaTeX 巨集、巢狀 `^[...]` 的數學字串：交由可選 KaTeX renderer；核心不宣稱完整 LaTeX 相容。
- Unicode ID 使用 NFC 正規化；零寬字元不視為可安全識別字元。
- 不規則縮排和清單內大量連續空白行：採 StructMark 自有確定規則，不宣稱完整 CommonMark 等價。
- 一般段落從行首展示 `&note`、獨立 `&end` 等保留指令時，必須使用跳脫或程式碼圍欄。
- `&raw` 或 `&data` 的獨立行 `&end` 仍為終止符；1.1 已提供 `\&end` 輸入字面文字。
- 混用不同連結指向同一個文件、相對路徑與跨檔 Wiki 連結的解析依賴 workspace API，不由單檔 Parser 猜測。

## 安全與確定性

- 無網路相依的 MIME 檢查，不將連結自動改成圖片。
- HTML Renderer 使用跳脫與 URL 協定白名單，其他輸出端須另作輸出格式的安全驗證。
- 單份來源文件大小與行內/區塊巢狀層數由呼叫端控制；核心已提供大型文件效能與 fuzz smoke test。
- fuzz 測試保證不崩潰與不洩漏，不代表形式驗證或完整標準相容性。

## V1.0 補充驗證

- 以 111 項自動化測試覆蓋來源區間、原始內容、清單續行、JSON 格位衝突、未知指令及壓力輸入。
- `&kbd[...]` 出現在行首時依然是行內語義，未知 `&custom[內容]` 不會自動吞掉後續文件。
- 結構化表格若有格位重疊、越界或缺格，診斷 `MMK-T002` 並避免生成不合法 HTML 表格。
- 目前已完成詞法層、workspace 參照驗證、Markdown common subset、Formatter、效能與 fuzz 測試；完整外部標準等價仍明確列為非目標。
