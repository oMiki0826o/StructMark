# Security Policy

## Supported versions

Security fixes are currently accepted for the latest `main` release.

## Reporting a vulnerability

Do not disclose an exploitable vulnerability in a public issue. Use GitHub's private vulnerability reporting for this repository when available. Include the affected version, a minimal reproduction, expected behavior, actual behavior, and any security impact.

The parser is designed not to execute source content or access the network and filesystem. Reports involving unsafe HTML, URL handling, diagnostics, denial of service, or dependency vulnerabilities are especially useful.
