# Code of Conduct

We want StructMark to be a constructive and respectful project for language and tooling work.

Participants must:

- communicate respectfully and assume good faith;
- focus criticism on ideas, code, and evidence;
- welcome different levels of experience;
- avoid harassment, discrimination, personal attacks, and unwanted contact.

Project maintainers may remove content or participation that violates these standards. Report concerns privately to the repository maintainers through the GitHub repository.
